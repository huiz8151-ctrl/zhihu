# 知途辩场 · 学习决策台

知乎黑客松第一版 HTML Demo 框架。

## 工作台结构

页面采用左侧工作台导航，分为四个模块：

- 主页（我的）：当前学习路径、进度、最近收藏和最近一次辩论
- 知识学习：问题输入、知识节点、学习路径和知乎经验
- 行业推演：三个 Agent 的观点交锋与综合结论
- 排行榜：热门学习路径、行业经验和项目实践主题

## 视觉风格

页面采用知乎内容工作台方向：浅灰应用背景、白色阅读画布、知乎蓝作为主操作色，配合细分割线和轻阴影。中文正文优先使用系统无衬线字体，英文和数字优先使用 Inter；避免大面积装饰色和复杂渐变，让问题、经验和路径成为主要视觉层级。

## 当前版本

本版本使用本地演示数据，已经搭建以下体验链路：

1. 从主页进入工作台
2. 输入学习问题
2. 选择个人背景
3. 查看知识路径
4. 阅读知乎经验卡片
5. 查看三个 Agent 的观点
6. 获得阶段化学习建议
7. 在排行榜中按主题筛选社区热度

## 本地运行

直接用浏览器打开 `index.html` 即可体验。也可以使用任意静态文件服务器预览。
